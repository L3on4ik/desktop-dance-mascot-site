About the project
Independent Windows project · In development

A little character.
A lot of rhythm.

Desktop Dance Mascot brings a 2D animated companion to your Windows desktop. The project is exploring music-aware movement, customizable dance animations, and smooth transitions between dances.

Explore the project Music data & credits

What we're building

A lightweight desktop companion designed around animation and rhythm.

✦

2D desktop character

A transparent, movable animated character that stays on your desktop while you work or listen to music.

♫

Dance animation library

Multiple animated dance loops with rhythm annotations, with more dances and transition clips planned.

◷

Music-aware dancing

Planned BPM-based synchronization using track metadata, playback position, and optional timing calibration.

Music data & attribution

Desktop Dance Mascot is exploring third-party track metadata and tempo (BPM) lookup to support music-aware animations. GetSongBPM is a prospective music metadata provider. This independent project is not affiliated with or endorsed by GetSongBPM.
